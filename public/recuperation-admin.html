🆘 Récupération de l'accès administrateur

Procédure de secours — à utiliser uniquement en cas de blocage total

Cette page ne fonctionne que s'il n'existe plus aucun compte administrateur actif dans la base de données (par exemple si le dernier compte admin a été accidentellement rétrogradé en parent ou animateur). Si un administrateur est encore actif, cette procédure sera refusée par sécurité.

🔑 Clé de récupération

Cette clé est définie par le développeur du site (variable d'environnement ADMIN_RECOVERY_KEY sur Netlify). Si elle n'a pas été configurée, la valeur par défaut est PATRO-RECUP-2024 — pensez à la changer après usage !

♻️ Redonner le rôle Administrateur

Utilisez ceci si votre ancien compte admin (par exemple admin@patro.be) existe toujours mais a perdu son rôle.

➕ Créer un nouveau compte administrateur

Utilisez ceci si vous préférez repartir avec un tout nouveau compte admin.
